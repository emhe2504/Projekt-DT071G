I denna projektuppgift har jag skapat en konsolapplikation i form av en Att-Göra lista. 
Vid dotnet run tas användaren till applikationens startsida och själva Att-Göra listan.


Applikationen har en huvudmeny där varje nummer i menyn leder till olika funktionalitet.
- Användaren kan lägga till en uppgift som sparas i en JSON-fil.
- Användaren kan uppdatera status på en uppgift.
- Användaren kan ta bort en uppgift.
- Användaren kan se statistik för hur det går med att bocka av uppgifter.
- Användaren kan stänga ner applikationen.


Jag hoppas att alla delar ska fungera!
